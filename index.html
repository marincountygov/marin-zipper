About

Marin Zipper is a browser-only tool for creating password-protected ZIP files with ZIP AES encryption. It does not send the selected files to a server.

File name links

Some links to Marin Zipper can fill in parts of the ZIP file name for you. This is useful when another system sends you here with file name details already included in the link.

A file name link can use these fields:

  • currentdate adds today's date automatically. No value is needed.
  • county fills in the County field.
  • lastname fills in the Last Name field.
  • dob fills in the Date of Birth field.

Example:

index.html?currentdate&county=Marin&lastname=Garcia&dob=1980-01-01

If today's date were 2026-08-28, that example would create a ZIP file name like 2026-08-28_Marin_Garcia_1980-01-01.zip. You can still edit the fields before creating the ZIP.

Do not include sensitive information in file names unless your department has approved that naming format.

Encrypted ZIP compatibility

Marin Zipper creates AES-encrypted ZIP files. Windows File Explorer cannot reliably extract encrypted archives. Use 7-Zip, WinRAR, WinZip, PeaZip, or another AES ZIP-compatible extractor to open files created with this app.
